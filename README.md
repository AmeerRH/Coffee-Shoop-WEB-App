☕ Coffee Shop Web App

A modern and responsive Coffee Shop web application built during my 3rd semester using only
HTML, CSS, and JavaScript.
The project runs on localhost and focuses on clean UI, smooth user experience, and core front-end logic without frameworks.

⸻

📌 Project Overview

This project simulates a real coffee shop website where users can:
	•	Browse the menu
	•	View product details
	•	Add items to cart
	•	Interact with a clean and modern UI
	•	Experience a responsive design for different screen sizes

The goal was to build a fully functional front-end app using only vanilla web technologies.

⸻

🛠️ Technologies Used
	•	HTML5 – page structure
	•	CSS3 – layout, animations, responsive design
	•	JavaScript (Vanilla JS) – logic, interactivity, DOM manipulation
	•	Localhost – for development and testing

No frameworks — everything was built from scratch.

⸻
